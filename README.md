# OficinaTech Pro

Sistema de gestão para oficinas mecânicas desenvolvido em Python.

## Sobre o Projeto

O OficinaTech Pro foi criado para auxiliar oficinas mecânicas no controle de clientes, veículos e ordens de serviço de forma simples e organizada. O sistema possui interface gráfica moderna desenvolvida com CustomTkinter e utiliza SQLite para armazenamento dos dados.

## Funcionalidades

* Login de usuários
* Cadastro de clientes
* Cadastro de veículos
* Cadastro de ordens de serviço
* Controle de status dos serviços
* Histórico de atendimentos
* Dashboard administrativo
* Gráficos estatísticos
* Geração de relatórios

## Tecnologias Utilizadas

* Python 3
* CustomTkinter
* SQLite
* Matplotlib
* Tkinter

## Objetivo

Facilitar a administração de oficinas mecânicas, centralizando informações de clientes, veículos e serviços em uma única plataforma.

## Como Executar

Instale as dependências:

```bash
pip install customtkinter matplotlib
```

Execute o sistema:

```bash
python autotech_oficina.py
```
